# Карта затрат COSTOTA

Карта, на которой видно, сколько стоит каждый сервер, облако и платный API, чей он и насколько загружен. Простаивающие серверы она находит сама, и заявку на их вывод в DevOps можно отправить прямо с карты. Это модуль COSTOTA, внутреннего сервиса, который считает расходы компании на инфраструктуру. Проект НИС «Промышленное программирование 1», ВШЭ, осень 2026.

Модуль уже работает в компании, с 10.11.2026 (релиз COSTOTA 1.0.109). Код компании закрытый, поэтому здесь документы. Выкладываю их по мере сдачи контрольных точек, сейчас здесь КТ-1.
